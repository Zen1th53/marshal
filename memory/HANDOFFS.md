# HANDOFFS.md — Recent Cross-Agent Handoffs

## Rule

Keep only handoffs needed to resume the current work.

This is not permanent history.

Canonical detailed format lives in `protocols/HANDOFF.md`.

---

## Retention

Keep:

- current-task handoffs,
- latest predecessor handoff,
- handoffs referenced by open findings/blockers.

Consolidate older useful knowledge into:

- `STATE.md`,
- `DECISIONS.md`,
- `MEMORY.md`,
- ADR/design/test/security artifacts.

Do not keep an endless transcript.
