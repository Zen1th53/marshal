# MCP 2026-07-28 Mapping

## Why MCP

MCP is the tool/context/data integration boundary.

Use it for:
- memory service tools,
- repository/context services,
- policy/approval tools,
- controlled external tools.

Do not use MCP as a substitute for Agent OS role authority.

## Version Pin

Agent OS V6 pins the compatibility profile to:

```text
2026-07-28
```

The helper uses exact-version compatibility by policy.

This is intentionally conservative because the 2026-07-28 release contains
substantial protocol changes and a stateless core.

## Extensions

MCP extensions must be:
- explicitly negotiated,
- versioned,
- reviewed,
- deny-by-default when unknown.

## Tool Output

MCP tool output is external/tool evidence, not trusted policy.

Apply:
- `protocols/INSTRUCTION-TRUST.md`
- `protocols/CAPABILITIES.md`
- `protocols/DATA-GOVERNANCE.md`
