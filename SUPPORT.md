# Support

Use GitHub Issues for reproducible bugs, documentation defects, and focused
feature requests. Include `marshal version`, the commit when relevant, OS and
architecture, Go version for source builds, provider state, reproduction steps,
and sanitized logs.

Before filing:

```bash
marshal doctor
marshal adapters
marshal status
```

Search existing issues and [Troubleshooting](docs/troubleshooting.md). Never
post credentials, tokens, private source, `.marshal/` databases, or unsanitized
logs. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).

Support is best effort. Commercial licensing information is in
[COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md).
