# MARSHAL Support Policy

Welcome to the MARSHAL community support portal.

---

## Getting Help

### 1. Documentation & FAQs
Before opening a support issue, please consult:
- [README.md](README.md) — Landing page & quick start
- [docs/README.md](docs/README.md) — Complete documentation hub
- [docs/troubleshooting.md](docs/troubleshooting.md) — Diagnostics and recovery guide

### 2. GitHub Issues (Bug Reports & Feature Requests)
- **Bug Reports**: Open a [Bug Report](https://github.com/Zen1th53/marshal/issues/new?template=bug_report.yml) on GitHub. Please include output from `marshal doctor` and logs with redacted credentials.
- **Feature Requests**: Open a [Feature Request](https://github.com/Zen1th53/marshal/issues/new?template=feature_request.yml).

### 3. Security Vulnerability Reports
**DO NOT** submit security vulnerabilities through public GitHub issues. Please follow the instructions in [SECURITY.md](SECURITY.md) for confidential reporting.

---

## Release Support Life Cycle

- **Current Release Line (`v1.0.x`)**: Active maintenance and security bug fixes.
- **Historical Releases (`v0.4.0` and earlier)**: Archived under historical Apache-2.0 grants; security patches backported for critical flaws upon request.
