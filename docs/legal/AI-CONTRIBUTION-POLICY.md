# AI-Generated Contribution Policy

As an AI-agent execution, verification, and supervision platform, SLAVES acknowledges the use of AI tools and code-generation models in software engineering. This policy establishes clear IP provenance standards for AI-assisted or AI-generated contributions.

---

## 1. Provenance & Compliance Requirements

Contributors utilizing AI coding assistants (such as LLM code generators, agentic coding models, or autocomplete tools) must ensure that all submitted contributions comply with the following standards:

1. **Disclosure**: Material code snippets or modules generated with AI assistance must be disclosed in the Pull Request description.
2. **No Proprietary Contamination**: Contributors must not knowingly submit AI outputs generated from prompts containing confidential, trade-secret, or proprietary source code that the contributor is not authorized to license.
3. **No Incompatible Copyrighted Output**: Contributors must verify that AI outputs do not verbatim reproduce substantial blocks of third-party copyrighted code under incompatible licenses (e.g., GPL, AGPL, or proprietary source).
4. **Human Verification**: All AI-assisted code must be reviewed, tested, and verified by the human contributor prior to submission. The contributor assumes full legal responsibility for the contribution under their executed Contributor Assignment Agreement (ICAA/CCAA).

---

## 2. Prohibited AI Submission Practices

The following are strictly prohibited:

* Submitting AI-generated code known to infringe third-party intellectual property or copyright;
* Using AI tools to bypass third-party open-source license disclosure requirements;
* Disguising third-party licensed code as "original AI generation";
* Submitting unverified machine-generated code that breaks runtime invariants or security controls.

---

## 3. Assignment of Rights

Under the terms of the SLAVES Contributor Assignment Agreement (ICAA/CCAA), the contributor warrants that they possess all legal rights necessary to assign the contribution to the SLAVES copyright owner, including any rights created or acquired through the use of AI generation tools.
