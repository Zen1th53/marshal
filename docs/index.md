# MARSHAL

MARSHAL is a terminal workspace for coordinating coding agents in a Git project.
It is for developers who want to plan work, approve its scope, inspect evidence,
and decide when the result is ready.

Version **0.0.5** adds a conversational Marshal, an editable plan pack, isolated
worker tasks, explicit acceptance and return, project-scoped session selection,
and checkpoint previews. Commands report unavailable capabilities rather than
pretending work succeeded.

Start with [installation](public/installation.md) and the
[five-minute first conversation](public/getting-started.md). Then follow the
[Marshal guide](public/marshal.md), choose [providers](public/providers.md),
and keep the [command reference](public/tui.md) nearby.

Read the [concepts and limits](public/concepts.md),
[troubleshooting](public/troubleshooting.md), and [0.0.5 release notes](public/release-notes.md).
