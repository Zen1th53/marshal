# MARSHAL Project Governance

This document describes the project governance model for MARSHAL.

---

## Maintainership

MARSHAL is authored and maintained by **Zen1th53** (`Behruz <extreme29@proton.me>`).

### Project Principles
1. **Technical Restraint**: Understand first, change the minimum necessary, verify completely, submit atomically.
2. **Security-First Positioning**: No capability is claimed without empirical test evidence and fail-closed security invariants.
3. **Zero Noise**: Every commit and pull request must represent one coherent, technical change.

---

## Decision Making

All architectural, security, and release decisions are reviewed against:
- Established BlackArch / Arch packaging standards
- MARSHAL TERRA specification contracts
- Verification test suite results
