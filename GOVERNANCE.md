# Governance

MARSHAL is maintained by Zen1th53. There is no foundation, steering committee,
or delegated release council.

The maintainer has final responsibility for roadmap, security response,
compatibility, licensing, releases, and merge decisions. Technical decisions
follow repository evidence, security invariants, tests, and the smallest
maintainable implementation.

Contributions are reviewed for scope, correctness, security, compatibility,
documentation, test evidence, and contributor assignment status. Opening a
pull request does not guarantee acceptance. Discuss material changes before
substantial implementation work.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).
